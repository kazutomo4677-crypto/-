# イラストの 3D 化 (Blender)

参考イラスト（ヘッドホンと丸サングラスを着けて笑う女の子が、ヴィンテージの
ラジカセの上にあぐらで座っているポップな絵）を、Blender 上で手続き的に
3D モデル化してトゥーン調にレンダリングする一式です。

モデルは 1 本の Python スクリプトで完結していて、GUI での手作業は不要です。
`illustration_to_3d.py` を実行すると、シーンの生成 → 保存 → 書き出し →
レンダリングまでを一気に行います。

## 実行方法

```bash
# 既定 (900x1350 / 320 サンプル / front・hero・side・face の4カット)
blender -b -P blender/illustration_to_3d.py -- --out blender/renders --samples 320

# 素早く確認したいとき
blender -b -P blender/illustration_to_3d.py -- --out /tmp/preview --res 400 600 --samples 64 --views front

# モデルだけ書き出してレンダリングしない
blender -b -P blender/illustration_to_3d.py -- --out blender/renders --no-render
```

### オプション

| オプション | 説明 | 既定値 |
| --- | --- | --- |
| `--out DIR` | 出力先ディレクトリ | `blender/renders` |
| `--samples N` | Cycles のサンプル数 | `96` |
| `--res W H` | 解像度 | `900 1350` |
| `--views a,b,c` | `front` / `hero` / `side` / `back` / `face` | `front,hero,side,face` |
| `--no-render` | `.blend` と `.glb` だけ書き出す | - |

## 出力

| ファイル | 内容 |
| --- | --- |
| `renders/front.png` | 正面（元イラストと同じ構図） |
| `renders/hero.png` | 32° の斜めからのカット |
| `renders/side.png` | 72° の横からのカット |
| `renders/face.png` | 顔まわりのクローズアップ |
| `renders/illustration_3d.blend` | Blender のシーンファイル |
| `renders/illustration_3d.glb` | glTF (Web ビューア等で確認可能) |

## 作りの説明

### モデリング方針

ボーンやスカルプトを使わず、**プリミティブの重ね合わせ**と
**パラメトリックな格子サーフェス**だけで組み立てています。
不透明な形状どうしは重ねてもシルエットに影響しないため、
ブーリアンを使わずに済ませています。

主なヘルパ:

- `prim()` — 球 / 円柱 / 円錐 / トーラス / 立方体を、原点で作りスケールを
  適用してから配置する
- `tube()` — 制御点ごとに半径を変えられる NURBS チューブ。腕・脚・
  ヘッドバンド・靴ひもなどの「太さが変わる曲がったもの」全般に使用
- `grid_mesh()` — `fn(u, v) -> Vector` で定義した格子サーフェス。
  髪・ジャケット・顔のパーツはすべてこれ
- `head_point(az, el)` — 頭部の楕円体上の座標と法線を返す。
  目・口・チーク・サングラス・ヘッドホンの位置はすべてこの座標系で
  指定しているので、`HEAD_R` を変えれば全部が追従する

### 各パーツ

- **髪** — 生え際の高さ `hairline(az)` と毛先までの長さ `hair_len(az)` を
  方位角の関数として定義し、頭に沿う部分と垂れ下がる部分を 1 枚の
  連続したサーフェスとして生成。下に行くほど外に広がり、緩いウェーブが入る
- **顔** — 楕円体の表面に貼り付く薄いパッチとして、口・歯・目・眉・
  チークを生成（`head_patch()` / `head_arc()`）。顔の曲面に正確に沿う
- **ジャケット** — 前を開けた 2 枚のシェル + ソリッド化モディファイア。
  襟・ワッペン・ドローコードを追加
- **ラジカセ** — ベベルを掛けた箱に、スピーカー・チューナー・つまみ・
  ハンドルを配置

### シェーディング

- Cycles の **Toon BSDF**（拡散）でセル調の陰影。
  プラスチック系は少量のトゥーン光沢を混ぜている
- サングラスのレンズは光の影響を受けないよう **Emission + 透過**で
  フラットな色に（元イラストの塗りに合わせるため）
- **Freestyle** で被写体のみに輪郭線（背景にはかからないよう、
  `Subject` コレクションで絞り込み）
- ビュー変換は `Filmic` ではなく **`Standard`**。フィルミックだと
  イラストの鮮やかな原色が眠くなるため
- ライトは弱めのキー / フィル / リム / バウンス + 強めの環境光。
  陰影より色面が主役になるバランスにしている

## 環境メモ

- Blender 4.0.2 (`apt install blender`) で確認
- Cycles は CPU。このビルドには OpenImageDenoise が同梱されていないため、
  スクリプトはデノイザーの有無を検出し、無ければサンプル数で品質を稼ぐ
  （既定の 320 サンプルはこの前提の値）
- glTF 書き出しには numpy が必要（`apt install python3-numpy`）。
  無い場合はスキップされ、`.blend` とレンダリングだけ出力される
